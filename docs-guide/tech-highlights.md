# ResumeMind 技术亮点（答辩口径）

ResumeMind 是面向"面试官 × 简历主人公"场景的问答 Agent：面试官对简历任意提问，系统结合知识库（简历/证书/荣誉/项目文档）作答。与通用 RAG 平台（Dify/FastGPT/RAGFlow 等）相比，本系统有四个工程化亮点。

## 亮点 1：置信度分级回答 + 答案自评（Self-RAG 式证据自评）

**实现**：LLM 生成时同步输出 `{answer, evidence_sufficiency, reason}` 自评结构；后端按三档分级——`sufficient` 直接实答、`partial/insufficient` 强制"根据现有知识库推测"前缀（LLM 先行、后端兜底补前缀保证措辞统一）、`greeting/off_topic` 走礼貌转移模板（零 LLM）。分级结果 `answer_mode` 随 API 透出。

**为什么比普通 RAG 强**：普通 RAG 是"检索 → 生成"的单行道，没有"回答可信度"的显式信号——检索弱时要么硬编（幻觉）要么硬拒（体验差）。本设计把"证据充足度"变成模型显式自评 + 后端强制分级：面试官一眼区分"简历实答"与"合理推测"，既不夸大事实、也不因求精确而拒答。开放性问题居多的面试场景下同时满足诚实与可用。

## 亮点 2：LLM 意图分类 + 追问补全（认知中间层，主流 RAG Router 思路）

**实现**：一次小 LLM 调用合并完成「3 类意图分类（resume_qa/greeting/off_topic）+ 指代消解」双职责——寒暄/无关话题零检索零生成走礼貌转移，其余全部进完整 RAG 主链；分类失败保守回退 resume_qa，意图层绝不当掉任何检索机会。查询改写（LLM 生成检索式变体）在兜底链第 2 级触发。

**为什么强**：普通 RAG 对一切问题一视同仁地"检索+生成"，无关问题硬检索 → 高幻觉、高延迟。本设计把 LLM 预算花在刀刃上：问候/无关话题零检索零生成；分类与消解合并为一次调用，每问 LLM 调用数固定为 3（分类消解 + 规划 + 生成），2C4G 下端到端稳定 <6s。纯 LLM 判定替代关键词表：无词表误伤（如"你好，介绍下你的项目"被整题转移为寒暄），也无领域词表维护负担。

## 亮点 3：多轮追问记忆（Dify 会话记忆思路）

**实现**：前端 localStorage 持久化 `session_id` + SQLite `conversation_turns` 表 + 进程内 LRU（24h TTL）；指代消解已并入亮点 2 的意图调用（提供上一轮摘录、LLM 自动补全），记忆层只负责轮次存取——"那怎么解决超卖的？"被补全为带上下文的完整问题后进检索。

**为什么强**：面试本质是多轮深度追问，无状态 RAG 对依赖前文的追问必然检索失败。带记忆后追问链可连续深挖，这是"面试模拟"类产品与普通文档问答的本质差异；消解与分类合并为一次调用，无额外 LLM 成本。

## 亮点 4：检索兜底链（降阈重试 → 改写重试 → LLM 推理）

**实现**：四级流水线——① 标准检索（宽松门槛）→ ② 降阈重试（阈值 0.05、强制 min 6 块）→ ③ LLM 改写后重检索 → ④ 无检索直接生成（persona + 会话历史，强制推测标注）；`retrieval_fallback_level` 全程透出便于观测。枚举类问句（"参与过哪些项目"）走通用枚举机制：planner prompt 注入**运行时知识库文档清单**（动态查询 Document 表，非硬编码）按对象逐项拆 aspect、检索查询引用文档名锚点、全量 rerank + prompt 容量放宽兜底，保证被列举对象全部进上下文。

**为什么强**：普通 RAG 单次检索失败即"未找到"，丢掉了面试官口语化/长尾提问。兜底链把"找不到"转化为"放宽标准再找 → 换个说法再找 → 基于简历已知信息合理推断并标注"，配合亮点 1 的自评保证诚实不编造，覆盖刁钻提问的最坏情况且永不拒答。

## 架构取舍（诚实版）

- **检索依赖模型质量**：词法通道全部移除后，精确名称/数字召回依赖 embedding/rerank 语义排序；枚举类问句靠 planner 枚举规则 + 全量 rerank 兜底覆盖。
- **LLM 依赖**：DeepSeek 外部 API，离线时降级为摘录 + 礼貌转移（功能大减）。
- **吞吐有限**：embedding/rerank 串行、全局并发 4、单机 SQLite——面向面试场景的单访客高频追问，够用。
- **推测标注的边界**：硬事实（数字/日期/机构/证书名）仍强制来自检索片段，只有"组织/推断/衔接"允许适度发挥——标注机制保证面试官能区分。
