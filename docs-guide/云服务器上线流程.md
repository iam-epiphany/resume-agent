# 云服务器上线流程

> 材料主题：系统说明

本流程面向面试官问答服务，目标是先保证知识库可信和模型已就绪，再开放公网访问。

## 上线前

1. 仅把已经审核的正式 Markdown 放入 `docs/` 第一层；原始聊天记录、PDF、评测报告和系统说明不得放入该目录。
2. 在服务器的 `.env` 填写有效的管理员密码、JWT 密钥、DeepSeek 密钥；若启用问答访问码，访问码须符合配置规定的 6 位大写字母或数字格式。
3. 执行 `python scripts/preflight_deploy.py`。检查失败时先处理错误，不要启动面试官入口。

## 启动与预热

```powershell
docker compose up -d --build
docker compose ps
```

默认配置会阻塞预热，并限制为 2 个并行问答任务、8 个重排候选。模型未就绪时不应把反向代理流量转到公开问答入口。

## 重建知识库

首次上线或资料发生删除、改名时，以 `docs/` 第一层为唯一事实源同步：

```powershell
$env:ADMIN_PASSWORD = '仅在当前终端设置，不要写入命令历史'
python scripts/upload_knowledge_base.py --sync
```

`--sync` 会删除服务端中不在当前扫描清单里的旧文档，然后上传或更新当前正式资料。此操作会改变运行时知识库；执行前应确认 `docs/` 第一层文件清单无误。

## 验收

管理员口径执行：

```powershell
python scripts/eval_interview_set.py --data scripts/eval_cases.jsonl --admin-password $env:ADMIN_PASSWORD --max-p95 6 --max-llm-calls-p50 1 --report data/eval-report.json
```

若 P95 未达到 6 秒，先查看重排耗时与缓存命中率；不要通过开启无证据直接生成来掩盖检索问题。
