# 面试官问题集（回归语料 v1）

用于架构改造（"可信/精确" → "宽松推理"）前后的回答质量对比与回归验证。每类问题记录改造前后的回答质量（事实错误数、推测标注合规、转移自然度、追问链连贯性、端到端耗时）。

## A. 自我介绍类

1. 请介绍一下你自己
2. 用三个词形容你自己
3. 你最大的优势是什么
4. 你还没毕业，为什么现在找实习
5. 你什么时候可以到岗

## B. 项目深挖类

1. 介绍一下你的秒杀项目
2. 秒杀怎么防止超卖
3. 为什么用 Redis 预扣库存不用数据库锁
4. 这个秒杀项目跑过多少并发
5. 外卖平台的微信支付流程是怎样的
6. 微信支付回调怎么防止重复处理
7. 什么是 grounding 校验
8. 多 Agent 是怎么编排的
9. NTT 数论变换是干什么的
10. 你的简历写了 Kafka，项目里是怎么用的

## C. 技术八股类

1. 你的 Java 水平怎么样
2. HashMap 的原理是什么
3. 缓存穿透、击穿、雪崩怎么解决
4. Kafka 怎么保证消息不丢
5. 为什么 B+ 树适合做索引
6. Redisson 分布式锁会失效吗

## F. 无关话题类（应礼貌转移）

1. 你好
2. 谢谢
3. 在吗

## H. 追问链（多轮记忆验证）

1. 链 1：介绍一下你的秒杀项目 → 那超卖怎么防的？ → 为什么不用数据库锁？
2. 链 2：你的技术栈是什么 → Java 这块水平怎么样 → 那 Redis 呢？
3. 链 3：你本科在哪个学校 → 学了哪些课 → 哪门学得最好？
4. 链 4：你平时有什么爱好 → 会打篮球吗？

## 评分维度

- **事实错误数**：硬事实（数字/日期/机构/证书）错误个数，0 为合格
- **推测标注合规**：证据不足时是否带"根据现有知识库推测"前缀
- **转移自然度**：无关/寒暄问题的回答是否自然、不冷硬
- **追问链连贯性**：H 组追问是否能正确指代消解
- **端到端耗时**：目标单问 < 6s（2C4G）
